# Amártir — portfolio redesign

Redesign concept for [Amártir](https://sites.google.com/view/amartir/inicio), the fashion label of Juanjo Villegas (designer and pattern maker, Granada).

- `index.html` — current direction: image-led bento grid; every tile opens into its own page
- `draft-1.html` — first draft: editorial single page with a swipeable collections rail
- `img/` — photography from the current Amártir site

Both pages are plain HTML/CSS/JS with no build step. Light theme, Spanish/English toggle, Apple-style spring motion (interruptible, velocity-aware), and `prefers-reduced-motion` support.

To view locally, open `index.html` in a browser.
